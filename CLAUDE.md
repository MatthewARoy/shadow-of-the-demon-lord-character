# Project guidance for Claude

## Contributor policy

Claude must **never** be credited as a contributor to this codebase. This
applies to every commit, pull request, and any other artifact in the repo.

Specifically, when committing or creating PRs:

- Do **not** add `Co-Authored-By: Claude ...` trailers to commit messages.
- Do **not** add `Claude-Session:` (or any session-link) trailers.
- Do **not** add the 🤖 "Generated with Claude Code" line to PR bodies.
- Do **not** set Claude/Anthropic as a git author or co-author in any form.

Commit and PR authorship should reflect only the human contributor(s).
